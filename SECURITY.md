# Política de segurança

Não publique vulnerabilidades, senhas, tokens ou dados reais em uma issue. Para este projeto
acadêmico, comunique o responsável pelo repositório em canal privado e informe a versão afetada,
o impacto observado e uma forma segura de reproduzir o problema.

As credenciais presentes em arquivos `*.example` são apenas marcadores. A aplicação de demonstração
aceita tokens fictícios; nunca use número de cartão ou dado pessoal real.
